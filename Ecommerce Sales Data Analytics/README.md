# 🛍️ E-Commerce Sales Analysis & Performance Dashboard

## 📌 Project Overview
Explored an e-commerce dataset to identify sales trends, evaluate profitability across regions/categories, and build visual reporting dashboards.

## 🛠️ Tools Used
- **Microsoft Excel:** Data Auditing, Outlier Detection, Advanced Formulas (`XLOOKUP`, `SUMIFS`, nested logic)
- **Power Query:** Data Cleaning and Transformation
- **Pivot Tables & Charts:** Dynamic Dashboarding with Slicers

## 🔑 Key Deliverables
- Resolved missing values, duplicate entries, and statistical outliers across customer and sales tables.
- Computed core KPIs including **Total Revenue**, **Profit Margins**, and **Average Order Value (AOV)**.
- Built interactive dashboards enabling leadership to slice sales performance by store type, product category, and geographic region.
